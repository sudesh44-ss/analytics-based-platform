## 2. Page Sections Implemented

The `/audits` route is composed of the following sections conforming to the SiteScope design system:

### A. Page Header & Actions
- **Heading:** `Technical SEO Audits`
- **Description:** `Identify technical SEO issues, monitor website health, and improve search engine discoverability.`
- **Actions:** 
  - `Refresh`: Manual trigger to re-query the latest project audit history and metrics.
  - `Run New Audit`: Primary action button that toggles the audit configuration drawer.

### B. Project & Website Selection Bar
- Project dropdown selecting from authorized user projects via [`getProjects()`](file:///H:/analytics-based-platform/frontend/src/lib/api.ts).
- Displays website hostname, active project domain, latest audit status badge (`Completed`, `In Progress`, `Failed`), and last audited timestamp.
- Displays an empty state with a direct CTA to `/projects` if the user has no registered websites.

### C. Run New Audit Workflow (Configuration Drawer)
- Allows selecting:
  - **Max Pages:** `10`, `25`, `50` (Standard), `100`, `250` (Deep).
  - **Crawl Depth:** `1` (Homepage), `2`, `3` (Standard), `5` (Deep).
  - **Playwright Headless Browser:** Checkbox to toggle full JavaScript DOM rendering.
- Submits to Fastify's `POST /api/v1/audits`, reserving PostgreSQL daily audit quota atomically and enqueuing jobs into BullMQ.
- Automatically polls until the crawl finishes and refreshes the table and KPI cards.

### D. SEO Summary Metrics (KPI Cards)
Powered by real backend metrics from `GET /api/v1/dashboard/summary`:
- **Technical SEO Score:** Displays score/100 colored dynamically (Green $\ge 80$, Yellow $\ge 50$, Red $< 50$).
- **Pages Crawled:** Real count of crawled pages versus the audit page ceiling.
- **Critical SEO Issues:** Count of critical issues requiring immediate remediation.
- **Warnings & Medium:** Aggregated high and medium severity findings.
- **Daily Audits Remaining:** Displays quota ledger remaining vs daily limit.

### E. Audit History Table
- Filterable by audit status (`All`, `Completed`, `Crawling`, `Queued`, `Failed`).
- Columns: `Website Domain`, `Audit Date`, `Status`, `Health Score`, `Pages Crawled`, `Config`, and `Actions`.
- Actions provide a direct link to [`/audits/${audit.id}`](file:///H:/analytics-based-platform/frontend/src/app/audits/[auditId]/page.tsx) to inspect raw pages and issue occurrences.

### F. Technical SEO Issue Breakdown
- Pulls live issues from `GET /api/v1/audits/:auditId/issues` filtered for `SEO` and `TECHNICAL_HEALTH` categories.
- Severity filter chips (`ALL`, `CRITICAL`, `HIGH`, `MEDIUM`, `LOW`).
- Displays issue title, severity badge, score impact, description, recommendation, and deep-link to the affected URLs inspection page.
